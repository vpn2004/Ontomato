## 范围与固定产物

本轮优化位于 Core 的 V2 根身份枚举：按对象前缀跳过其余属性键，继续合并 legacy 属性和独立身份 marker。应用本轮没有产品改动，沿用 [T34 计量与联合验收](onn-core-t34-detail-observability-20261109.zh-CN.md)的固定 adapter JAR，SHA256 为 `0b247a253f28cdb139350aeed067aaf208ce49b4c7fdc8877c5d483983538884`。Core 实现提交为 `60c7c1dc`。

没有新增协议、持久化索引、跨请求身份缓存或开关；保留空对象、历史无 marker 对象、权限、稳定读、预算、事务冲突及错误整次拒绝语义。写事务、正数扫描 limit、包装存储和不适用票据保留旧扫描路径。应用的用户 LiveInstanceGraph 既有改动与私有运行配置未纳入本轮；未推送、未切换生产入口。

行为边界以 Core [T35 契约](../../../onn-core/docs/t35-identity-enumeration.zh-CN.md)为准，最终结论以 Core [T35 验收报告](../../../onn-core/docs/acceptance/t35/report.zh-CN.md)归档为准。相对路径适用于当前两仓布局。
